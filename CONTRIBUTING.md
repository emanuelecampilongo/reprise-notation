# Contributing to Reprise Notation

Email [info@emanuelecampilongo.com](mailto:info@emanuelecampilongo.com) to report a bug, suggest a feature, or propose a code change. Email is the only channel for receiving and discussing contributions to Reprise Notation. To copy the address from the app, open **Help → Feedback…**.

For a bug report, include your Reprise Notation version from **Help → About Reprise Notation**, your Windows version, and the steps to reproduce the problem. Describe what you expected and what happened. If the problem depends on a specific score, you can attach a small example you have permission to share.

For a proposed change, describe the problem or use case and what you would like to change. If you already have a patch, attach it to your email and describe how you tested it.

## Build on Windows

Reprise Notation uses the MuseScore Studio toolchain. See the [upstream build prerequisites](https://github.com/musescore/MuseScore/wiki/Set-up-developer-environment) and the [Reprise Notation MSIX packaging instructions](buildscripts/packaging/Windows/REPRISE-DISTRIBUTION.md).
